# Verification model

ProofRails verification answers a narrow but important question:

> Does the submitted receipt evidence match the expected record and onchain anchor data?

It can check:

- evidence bundle hash
- stored receipt metadata
- anchor transaction reference
- bundle URL contents where accessible
- CID references where supported

It does not prove external business facts such as legal settlement finality, customer identity, sanctions screening, invoice validity, or bank acceptance.
