# Known limitations

Before production use, review the release checklist and current known limitations in the repository.

Common areas to verify:

- anchoring confirmation and retry behavior
- RPC reliability
- private key storage model
- rate limiting
- idempotency
- webhook signing and delivery retries
- x402 facilitator and token configuration
- frontend API proxy configuration
- receipt verification by URL and hash in the target deployment

If documentation and implementation disagree, trust the implementation and update the docs.
