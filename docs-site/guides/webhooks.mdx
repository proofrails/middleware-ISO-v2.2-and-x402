# Webhooks and events

The current `agentic` source supports HMAC-signed webhook subscriptions. This group was not present in the hosted OpenAPI snapshot checked on 24 July 2026, so confirm hosted rollout before registering a production callback.

## Event topics

```text
receipt.pending
receipt.anchored
receipt.failed
agent.anchored
*
```

## Manage subscriptions

```http
POST   /v1/webhooks
GET    /v1/webhooks
GET    /v1/webhooks/{webhook_id}
PUT    /v1/webhooks/{webhook_id}
DELETE /v1/webhooks/{webhook_id}
POST   /v1/webhooks/{webhook_id}/test
```

Create a subscription:

```json
{
  "url": "https://merchant.example/proofrails/webhook",
  "events": ["receipt.anchored", "receipt.failed"],
  "description": "Receipt completion"
}
```

The source limits a project to 10 subscriptions.

## Verify signatures

ProofRails sends the raw JSON body with:

```text
X-ISO-Event
X-ISO-Delivery
X-ISO-Timestamp
X-ISO-Signature-256: sha256=<hex>
```

Python verification:

```python
import hashlib
import hmac

def valid(raw_body: bytes, signature_header: str, secret: str) -> bool:
    supplied = signature_header.removeprefix("sha256=")
    expected = hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, supplied)
```

Verify the signature against the raw body before parsing JSON. Also reject stale timestamps and deduplicate on `X-ISO-Delivery`.

## SSE

For a single receipt, the source also exposes:

```http
GET /v1/iso/events/{receipt_id}
Accept: text/event-stream
```

Use webhooks for durable server-to-server delivery, SSE for a live UI, and status polling as a fallback.
