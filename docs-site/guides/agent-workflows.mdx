# Agent workflows

Agents can use ProofRails to produce receipts for autonomous actions and verify the evidence behind payment or workflow events.

Common capabilities:

- list receipts
- fetch receipt details
- check receipt status
- verify bundles
- generate statements
- create refund records
- anchor arbitrary JSON evidence
- list previous anchors
- verify an anchor hash

Use agents when the workflow needs a durable evidence trail without a human operating the dashboard.
