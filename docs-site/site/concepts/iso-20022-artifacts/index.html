ISO 20022-style artifacts

ProofRails translates onchain payment evidence into finance-readable XML. These documents preserve familiar ISO 20022 message names and namespaces, but availability and validation depth vary by generator.

Fetch receipt artifacts

curl --fail 'https://app.proofrails.com/v1/iso/messages/<receipt_id>' \
  -H 'X-API-Key: <api_key>'

Filter by type where supported:

GET /v1/iso/messages/{receipt_id}?type=pain.001

The response lists artifact type, path or URL and SHA-256 metadata.

Generation quality

pain.001.001.09 has a dedicated generator and schema path in the repository. Other generators explicitly describe themselves as minimal, pragmatic or best-effort, and some do not enforce XSD validation.

A well-formed XML response is not the same as:

  • conformance to every ISO 20022 XSD rule;
  • conformance to a specific market-practice guide;
  • semantic acceptance by a bank or clearing system;
  • ISO registration, certification or network connectivity.

Validate the exact message version, schema, business rules and market practice required by your recipient before production exchange.
