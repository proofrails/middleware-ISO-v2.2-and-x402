API overview

ProofRails exposes a FastAPI REST API.

Base URLs

https://app.proofrails.com    # hosted API
http://localhost:8000         # default local API

Runtime references:

  • Swagger UI
  • ReDoc
  • OpenAPI JSON
  • Health

The hosted OpenAPI is the source of truth for deployed routes. The agentic branch can contain capabilities that have not yet rolled out to the hosted service.

Authentication

Use a server-side API key unless a route is explicitly public:

X-API-Key: <api_key>

Project-scoped keys limit access to that tenant. Admin keys can access cross-project, configuration and analytics routes. Some deployments also support SIWE for wallet-linked access and key minting.

Common headers

Content-Type: application/json
X-API-Key: <api_key>
Idempotency-Key: <unique-logical-operation-id>

Responses can include request identifiers and rate-limit metadata depending on deployment configuration.

API groups

Operations Health, metrics, audit events and optional monitoring.

Version reality

The hosted OpenAPI checked on 24 July 2026 identified itself as version 0.1.0, while the current application factory in source identifies the service as 2.2.0. Do not use either string alone to infer route availability. Discover the runtime schema and pin the API behavior your integration depends on.
