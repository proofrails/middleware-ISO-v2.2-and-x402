Self-hosted deployments

Self-hosters can deploy separate EvidenceAnchor and X402Facilitator contracts. Keep those addresses out of application source and configure them through environment variables:

FLARE_RPC_URL=https://flare-api.flare.network/ext/C/rpc
ANCHOR_CONTRACT_ADDR=0x...
X402_FLARE_FACILITATOR_ADDRESS=0x...
X402_USDT0_FLARE_ADDRESS=0xe7cd86e13AC4309349F30B3435a9d337750fC82D

Never place a private key in documentation, client-side code or a committed .env file.
