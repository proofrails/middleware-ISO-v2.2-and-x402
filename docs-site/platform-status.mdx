## Known boundaries

- The mainnet-paid resource sequence uses a custom ProofRails config/unlock exchange rather than a canonical same-endpoint x402 V2 retry.
- The evidence bundle in the tested run does not include the SHA-256 hashes of the delivered PDF and Markdown files. The receipt therefore proves its own bundle integrity, not the exact downloaded resource bytes.
- The public verifier displayed a Coston2 explorer link for a valid Flare-mainnet anchor during the test. Use the mainnet transaction link shown above.
- Several ISO generators are intentionally minimal or best-effort. Treat them as translation artifacts, not evidence of ISO certification or bank acceptance.
