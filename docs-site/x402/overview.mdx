# x402 overview

ProofRails includes x402-style payment-gated API endpoints. The x402 layer is separate from the core receipt model: it controls access to premium actions, while ProofRails records and verifies evidence around payment activity.

Premium endpoint examples:

- paid bundle verification
- statement generation
- ISO artifact access
- FX lookup
- bulk verification
- refund workflow access

Use precise language: “x402 payment-gated API endpoints” is accurate. Do not imply unsupported payment networks or production settlement paths are live unless deployment configuration proves it.
