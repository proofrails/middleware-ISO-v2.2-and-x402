# Mainnet example

This read-only example shows the identifiers from one completed hosted request on 29 July 2026. Do not replay its authorization or nonce.

## Request and result

| Item | Value |
|---|---|
| Endpoint | `POST https://app.proofrails.com/v1/x402/premium/fx-lookup` |
| Client | Official x402 V2 packages `2.19.0` |
| Payment | `0.001 USD₮0` on Flare mainnet |
| HTTP result | `200` |
| Response body | `{"rate":"0.00628055","source":"coingecko"}` |
| Request ID | `b50f446e-f420-4afa-b196-5821bf0b5a92` |

[Open the settlement transaction](https://flare-explorer.flare.network/tx/0x5e4895837a68210f853f6e087de913b4d2c5ab573fe7b73f302026a8bebb6340)

The successful transaction emitted one `X402PaymentSettled` event with the expected USD₮0 token, payer, recipient, amount of `1000` base units, nonce and deterministic payment ID.

## What this example demonstrates

This example connects one paid HTTP request to a settlement, returned resource, receipt, signed evidence bundle and onchain commitment. It does not establish that every route, token or deployment mode has completed the same test.
